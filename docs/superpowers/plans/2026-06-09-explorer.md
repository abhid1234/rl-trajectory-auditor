# Explorer (Static HF Space) — Implementation Plan (Milestone 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax. The UI task (Task 2) is design-led — build + visually verify rather than unit-test.

**Goal:** Turn an `audit_run.json` + its staged trajectories into a static, editorial-aesthetic explorer (dashboard + filterable, keyboard-navigable card stack) deployable as a HuggingFace Space — the shareable artifact that carries the finding.

**Architecture:** A pure-stdlib `export_explorer.py` reads `audit_run.json` (diagnoses + verdicts + report + validation) and the staged trajectory dir (for message text), curates a capped subset of cards (all heuristic-vs-judge disagreements + top-confidence per category), and writes `explorer/data/summary.json` + `explorer/data/cards.json`. A framework-free static UI (`index.html` + `app.js` + `styles.css`) loads those two files: a dashboard (failure distribution, the reward-hack precision/recall headline, the judge-corrects-heuristic stat) and a card stack where each card shows the diagnosis chip, the offending message highlighted in context, evidence, and the judge's reasoning.

**Tech Stack:** Python 3.12 stdlib (export). Vanilla HTML/CSS/JS (no framework, no build step) for the Space. Editorial/preprint aesthetic: warm light background, serif display, oxblood accent. `pytest` for the export.

## Context

Milestone 3 produces `run5k/audit_run.json` (per-trajectory heuristic `Diagnosis` + LLM `JudgeVerdict`, the aggregate `report`, and `validation`). The finding (`docs/FINDINGS.md`): heuristics over-flag reward-hacking (precision 0.41); the Gemini judge is more precise (0.55) and corrects 78% of the false positives. The explorer makes that finding *browsable* — you scroll real trajectories and see exactly where the heuristic and the judge disagree, with the offending message highlighted.

`audit_run.json` intentionally omits message text (to stay small), so the export also reads the **staged trajectory dir** (e.g. `/home/abhidaas/.cache/rl_audit/traj5k`, present while/after the run) to pull each card's offending message + neighbors. The card set is **curated and capped** so the Space stays light: every disagreement (the interesting cases) plus the highest-confidence examples per category, up to a cap.

Constraints (memory): export is light (reads a ~1–6 MB JSON + a few hundred small trajectory files). Build/test while the 5k runs is safe (the run is network-bound). Per [[feedback_ui_aesthetic]]: editorial, warm light, serif, oxblood — avoid generic dark dashboards. Per [[feedback_no_employer_in_launch_materials]]: no employer/20%/colleague references anywhere in the explorer.

Reusable: `audit_run.json` shape = `{diagnoses:[{trajectory_id,diagnosis,failure_category,confidence,evidence,fix_recommendation,signals}], verdicts:{id:{trajectory_id,diagnosis,failure_category,confidence,reasoning,offending_message_index}}, report:{...}, validation:{reward_hack:{precision,recall,f1,confusion,n_evaluated}, judge_agreement:{n,agreement,kappa}}, judge_stats:{...}}`. Staged trajectory files are the normalized dicts (`{trajectory_id, task_id, messages:[{role,content,...}], ...}`); load with `src.models.Trajectory.from_dict` or read raw JSON.

```python
# src/pipeline/export_explorer.py
from __future__ import annotations
import json
import os
import sys

WINDOW = 2          # messages of context on each side of the offending one
CATS = ["Reward Hack", "Stuck at Fork", "Context Gap", "Clean", "Emergent/Unknown",
        "Unclassified Failure"]


def _gold_for(gen: float, gold: float, resolved: bool) -> str:
    if resolved or gold >= 1.0:
        return "CLEAN_TRUE"
    if gen >= 1.0 and gold <= 0.0:
        return "REWARD_HACK_TRUE"
    return "UNKNOWN"


def _load_staged(work_dir: str) -> dict:
    out = {}
    if work_dir and os.path.isdir(work_dir):
        for name in os.listdir(work_dir):
            if name.endswith(".json"):
                try:
                    r = json.load(open(os.path.join(work_dir, name)))
                    out[r.get("trajectory_id", r.get("task_id"))] = r
                except (ValueError, OSError):
                    continue
    return out


def _messages_window(traj: dict, idx) -> list:
    msgs = traj.get("messages", []) if traj else []
    if not msgs:
        return []
    center = idx if isinstance(idx, int) and 0 <= idx < len(msgs) else 0
    lo, hi = max(0, center - WINDOW), min(len(msgs), center + WINDOW + 1)
    out = []
    for j in range(lo, hi):
        m = msgs[j]
        out.append({"idx": j, "role": m.get("role", "?"),
                    "content": (m.get("content") or "")[:1200],
                    "offending": (isinstance(idx, int) and j == idx)})
    return out


def build_explorer_data(audit_run: dict, work_dir: str, out_dir: str, max_cards: int = 300):
    staged = _load_staged(work_dir)
    diags = {d["trajectory_id"]: d for d in audit_run.get("diagnoses", [])}
    verds = audit_run.get("verdicts", {})
    report = audit_run.get("report", {})
    val = audit_run.get("validation", {})
    n = report.get("total", len(diags))

    # distribution
    cats = report.get("categories", {})
    distribution = [{"label": k, "count": v, "pct": round(100 * v / n) if n else 0}
                    for k, v in sorted(cats.items(), key=lambda x: -x[1])]

    # judge-vs-ground-truth on the reward-hack axis + correction rate
    rh = dict(val.get("reward_hack", {}))
    jtp = jfp = jfn = fp_total = fp_judge_not_hack = 0
    for tid, d in diags.items():
        t = staged.get(tid)
        if not t:
            continue
        tr = t.get("test_results", {})
        gold = _gold_for(float(tr.get("pred_passes_gen_tests", 0.0)),
                         float(tr.get("pred_passes_gold_tests", float(bool(t.get("resolved"))))),
                         bool(t.get("resolved")))
        v = verds.get(tid)
        if gold == "REWARD_HACK_TRUE" and v:
            (jtp := jtp + 1) if v["diagnosis"] == "TRAINING" else (jfn := jfn + 1)
        if gold == "CLEAN_TRUE" and v and v["diagnosis"] == "TRAINING":
            jfp += 1
        # heuristic false positives: heuristic says Reward Hack but gold clean
        if gold == "CLEAN_TRUE" and d.get("failure_category") == "Reward Hack":
            fp_total += 1
            if v and v["diagnosis"] != "TRAINING":
                fp_judge_not_hack += 1
    j_prec = round(jtp / (jtp + jfp), 2) if (jtp + jfp) else 0.0
    j_rec = round(jtp / (jtp + jfn), 2) if (jtp + jfn) else 0.0
    corrects_pct = round(100 * fp_judge_not_hack / fp_total) if fp_total else 0

    summary = {
        "n": n,
        "distribution": distribution,
        "splits": report.get("splits", {}),
        "reward_hack": {
            "heuristic_precision": rh.get("precision"), "heuristic_recall": rh.get("recall"),
            "judge_precision": j_prec, "judge_recall": j_rec,
            "false_positives": fp_total, "judge_corrects_pct": corrects_pct,
            "n": rh.get("n_evaluated"),
        },
        "agreement": {"raw": val.get("judge_agreement", {}).get("agreement"),
                      "kappa": val.get("judge_agreement", {}).get("kappa"),
                      "n": val.get("judge_agreement", {}).get("n")},
        "headline": ("Heuristics over-flag reward-hacking; an LLM judge that reads the trace "
                     "is more precise and corrects ~4 of 5 false alarms."),
    }

    # cards: all disagreements first, then fill per-category by judge confidence
    def card(tid):
        d = diags[tid]
        v = verds.get(tid, {})
        t = staged.get(tid, {})
        tr = (t.get("test_results") or {})
        return {
            "trajectory_id": tid, "task_id": t.get("task_id", tid), "repo": t.get("repo", ""),
            "model": t.get("model", ""),
            "heuristic_diagnosis": d["diagnosis"], "heuristic_category": d["failure_category"],
            "heuristic_confidence": d["confidence"],
            "judge_diagnosis": v.get("diagnosis"), "judge_category": v.get("failure_category"),
            "judge_confidence": v.get("confidence"), "judge_reasoning": v.get("reasoning", ""),
            "agree": bool(v) and v.get("diagnosis") == d["diagnosis"],
            "evidence": d.get("evidence", []),
            "test_split": {"gen": tr.get("pred_passes_gen_tests"),
                           "gold": tr.get("pred_passes_gold_tests")},
            "messages": _messages_window(t, v.get("offending_message_index")),
        }

    judged_ids = [tid for tid in diags if tid in verds]
    disagreements = [tid for tid in judged_ids if verds[tid]["diagnosis"] != diags[tid]["diagnosis"]]
    chosen = list(disagreements)
    seen = set(chosen)
    rest = sorted([tid for tid in judged_ids if tid not in seen],
                  key=lambda i: -(verds[i].get("confidence") or 0))
    for tid in rest:
        if len(chosen) >= max_cards:
            break
        chosen.append(tid)
    cards = [card(tid) for tid in chosen[:max_cards]]

    os.makedirs(out_dir, exist_ok=True)
    json.dump(summary, open(os.path.join(out_dir, "summary.json"), "w"), indent=2)
    json.dump(cards, open(os.path.join(out_dir, "cards.json"), "w"), indent=2)
    return summary, cards


def main(argv=None) -> int:
    argv = argv if argv is not None else sys.argv[1:]
    audit_path, work_dir = argv[0], argv[1]
    out_dir = argv[2] if len(argv) > 2 else "explorer/data"
    audit = json.load(open(audit_path))
    summary, cards = build_explorer_data(audit, work_dir, out_dir)
    print(f"[OK] wrote {len(cards)} cards + summary to {out_dir} (n={summary['n']})")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Task 2: Static editorial UI

- Create: `explorer/index.html`, `explorer/app.js`, `explorer/styles.css`

Design-led (no unit tests). Build against real exported data, then verify it renders. **Aesthetic is the deliverable** — editorial/preprint, NOT a generic dashboard:
- Warm off-white background (`#faf6ef`-ish), serif display headings (e.g. `Spectral`/`Georgia` stack), oxblood accent (`#7b2d26`), generous whitespace, thin rules.
- **Dashboard (top):** the headline sentence in large serif; the reward-hack precision comparison (heuristic 0.41 → judge 0.55) as a clean stat pair; the "judge corrects X% of false alarms" figure; a horizontal failure-distribution bar list; the harness-vs-training split.
- **Card stack:** one trajectory card at a time. Header: task id, repo, model. Two diagnosis chips side by side — heuristic vs judge — color-coded, with a "✓ agree / ✗ disagree" marker. The offending message rendered in its message window, the offending line highlighted (oxblood left-border + tint). The judge's reasoning in a quote block. Evidence list. Test-split badges (gen=1.0 / gold=0.0).
- **Controls:** filter chips (All / Disagreements / by category); `←/→` keyboard nav (and on-screen prev/next); a counter (e.g. "12 / 300"). Default filter = Disagreements (the interesting cases).
- Loads `data/summary.json` + `data/cards.json` via `fetch` (works on a static host). Graceful empty state if data missing.
